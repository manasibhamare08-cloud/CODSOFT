# Iris Flower Classification

## Project Description
This project classifies Iris flowers into three species using Machine Learning.

## Dataset
Built-in Iris dataset from Scikit-learn

## Features Used
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Target
- Setosa
- Versicolor
- Virginica

## Model Used
Random Forest Classifier

## Accuracy
Expected around 95–100%

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
