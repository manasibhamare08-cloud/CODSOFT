# Credit Card Fraud Detection

## Project Description
This project detects fraudulent credit card transactions using machine learning.

## Dataset
creditcard.csv

## Features Used
- Time
- V1 to V28
- Amount

## Target
- Class
  - 0 = Genuine
  - 1 = Fraud

## Model Used
Logistic Regression

## Techniques Used
- Data preprocessing
- Class imbalance handling (undersampling)

## Evaluation Metrics
- Precision
- Recall
- F1-score

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
