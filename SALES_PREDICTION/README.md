# Sales Prediction Using Python

## Project Description
This project predicts product sales based on TV advertising expenditure using Simple Linear Regression.

## Dataset
Advertising dataset (TV, Radio, Newspaper, Sales)

## Feature Used
- TV

## Target
- Sales

## Model Used
Simple Linear Regression

## Evaluation Metrics
- RMSE
- R² Score

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
